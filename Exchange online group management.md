 - Three types of groups
 - Microsoft 365 Groups
o	What it is: A shared workspace for team collaboration.
o	Features: Includes a shared inbox, shared calendar, a SharePoint team site, a Planner board, and a Microsoft Teams chat room.
- 	Distribution Lists
o	What it is: A traditional email-only broadcast list.
o	Features: Used to send bulk announcements or emails to a static list of people. It has an email address, no shared workspace, and no security permissions.
-	Dynamic Distribution Lists
o	What it is: An automated email distribution list.
o	Features: Membership changes automatically based on predefined Active Directory/Entra ID attributes (such as department, job title, or office location) rather than manual updates.

-	Mail-Enabled Security Groups
o	What it is: A hybrid group used for both email and access control.
o	Features: Assigns access permissions to SharePoint, OneDrive, or other network resources, and can also receive email messages sent to the group address.
